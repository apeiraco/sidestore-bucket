# Changelog

## 0.1.0

### Added

- Bootstrap an automatically maintained SideStore and AltStore source with Tsumiru, JHenTai, and HaKa Comic.
- Add an Octokit-backed TypeScript CLI for release discovery, IPA verification, and deterministic source generation.
- Publish the latest stable app version with its actual build number, minimum iOS version, permissions, and SHA-256.
- Add mise and just workflows, offline tests, scheduled GitHub Actions updates, and generated VitePress documentation.
- Add concise English version descriptions, bilingual user documentation, and the custom Pages domain.
- Add prek commit checks and separate compatible development tools from the fully pinned CI toolchain.
